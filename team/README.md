# دليل الشركة (team/README.md)

المالك: [اسمك]. المدير التنفيذي: جلسة Claude Code وحدة، وهي الوحيدة اللي تكلّم المالك.

## الفريق
- سلمان، الباحث (researcher.md): يدوّر على الترندات والأفكار كل صباح.
- ماجد، الكاتب (writer.md): يكتب السكربت قبل التصوير بليلة.
- فهد، المونتير (editor.md): يمنتج الفيديو بنسختين.
- ناصر، الناشر (publisher.md): يجدول النشر بعد موافقة المالك.

## القواعد
1. كل تقرير يروح للمدير، مو للمالك.
2. حدّث اللوحة حسب board.md: لما تبدأ، لما تحتاج المالك، لما توقف، لما تخلص.
3. النشر والإرسال والصرف والدفع وتغيير الإعدادات: بموافقة المالك بس، لكل مرة لحالها.
4. «خلص» يعني قائمة التسليم كاملة (checklists.md).
5. ابقَ في مسارك: أي شغل برا وصفك يرجع للمدير.
6. أي تصحيح من المالك يصير قاعدة مكتوبة هنا.
7. كل تقرير بصيغة report.md.
