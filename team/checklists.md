# قوائم «خلص»

«خلص» يعني كل البنود معلّمة. المرجع الأصلي في ملف كل موظف.

## سلمان — الباحث
- [ ] القائمة فيها ٣ إلى ٥ أفكار، ولكل فكرة عنوان وسبب ومصدر برابط.
- [ ] الملف محفوظ في `research/` باسم تاريخ اليوم.
- [ ] الفكرة المقترحة الأولى معلّمة بوضوح.
- [ ] اللوحة محدّثة، والتقرير راح للمدير.

## ماجد — الكاتب
- [ ] السكربت محفوظ في `scripts/` قبل ليلة التصوير.
- [ ] فيه افتتاحية وقائمة لقطات وخاتمة.
- [ ] مدته المتوقعة مكتوبة.
- [ ] اللوحة محدّثة، والتقرير راح للمدير.

## فهد — المونتير
- [ ] النسختين جاهزة ومحفوظة في `edits/`.
- [ ] الصوت واضح والترجمة/النصوص صحيحة.
- [ ] صورة مصغّرة مقترحة لكل نسخة.
- [ ] اللوحة محدّثة، والتقرير راح للمدير.

## ناصر — الناشر
- [ ] خطة النشر مكتوبة (منصة، وقت، عنوان، وصف، وسوم).
- [ ] موافقة المالك موثّقة لهذي المرة بالذات.
- [ ] النشر مجدول، والرابط أو رقم الجدولة مسجّل.
- [ ] اللوحة محدّثة، والتقرير راح للمدير.
