# ملخصات الأيام

كل يوم الساعة 8:00 ص يكتب المدير ملف `days/YYYY-MM-DD.md` فيه:
1. وش لازم يسوي المالك اليوم (3 أشياء بالكثير).
2. خطة كل قسم بسطر واحد.
3. خطة بديلة ليوم صعب.

المصدر: اللوحة (المهام، needs المفتوحة، تسليمات وتقارير أمس) وملف أمس.
ممنوع في هذي المهمة: النشر، الإرسال، الدفع، أو تغيير أي إعداد.
